# ผีกบกระโดดถีบ

เกมสยองขวัญ 3D เล่นบนเว็บ (มือถือ/คอม) เล่นคนเดียวหรือกับเพื่อนสูงสุด 6 คน ไม่ต้องล็อกอิน ใช้รหัสห้อง 5 ตัว

## วางบน GitHub + Render
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นหน้าแรกของ repo (server.js, index.html, package.json, render.yaml, README.md)
2. Render → New → Web Service → เลือก repo → Runtime Node · Build Command: `echo ok` · Start Command: `node server.js`
3. Environment → เพิ่ม `ADMIN_CODE` = โค้ดแอดมินที่คุณตั้งเอง (ถ้าไม่ตั้งจะใช้ค่าเริ่มต้น `FROG-7391` ซึ่งไม่ปลอดภัย)
4. เปิดลิงก์ https://ชื่อ.onrender.com ส่งให้เพื่อน แล้วกด CREATE ROOM / JOIN ROOM

Render แผนฟรีจะหลับเมื่อไม่มีคนใช้ ครั้งแรกอาจรอ ~30–60 วินาที

## วิธีเล่น
WASD เดิน · Shift วิ่ง · Space กระโดด · E โต้ตอบ · F ไฟฉาย · คลิกซ้ายใช้อาวุธ · J สมุดบันทึก · V เปิดไมค์ · Enter แชต · F2 แอดมิน
มือถือ: เล่นแนวนอน จอยซ้าย ลากนิ้วขวามองรอบตัว

## แอดมิน
กดปุ่ม ADMIN เล็ก ๆ กลางบนจอ (หรือ F2) → ใส่โค้ด → เซิร์ฟเวอร์ตรวจสิทธิ์และบันทึก log ทุกคำสั่ง
